## Post 1: Technical Deep Dive

```
Today I learned: when Google geo-blocks you, it's not your IP — it's your phone number.

Tried 5 different approaches to parse 25 YouTube videos for our quant trading knowledge base:

❌ Gemini — blocked (China phone +86 on Google account)
❌ yt-dlp — version too old, can't upgrade (network issues)
❌ CLI proxy — v2rayA routes YouTube direct (timeout)
❌ Third-party APIs — all JS-rendered, nothing to scrape

✅ Chrome CDP + DOM extraction via ZeroOmega proxy

The fix wasn't changing the network — it was changing the layer. YouTube renders transcripts in the DOM. Extract from what's already there instead of fighting APIs.

21/25 videos processed. 1.5M characters parsed. ~25 min total with 5 parallel AI agents.

Sometimes the best API is no API at all.
```
